# Learn AI Open Lab Roadmap

Learn AI Open Lab aims to make practical AI education accessible to beginners, educators, creators and small business owners. The roadmap is intentionally learner-led. Ideas are welcome through issues and discussions after the repository is published.

## Modules

1. **AI Prompt Lab — Available now.** A browser-based workbench for comparing prompts, checking prompt quality, studying examples, saving notes, importing/exporting work and reviewing AI responses.
2. **AI Automation Lab — Planned.** Beginner automation workflows and tutorials, with visual recipes, trigger-and-action lessons, safety checks and reusable templates.
3. **AI Video Lab — Planned.** Practical AI video production and avatar workflows for creators and educators, including storyboards, shot planning, captions and responsible-use guidance.
4. **AI Coding Lab — Planned.** Beginner coding exercises and projects supported by AI, with debugging practice, code explanation prompts and testing habits.
5. **AI Business Lab — Planned.** Practical AI workflows for small businesses, covering research, customer support, operations and content while keeping human judgment in the loop.
6. **AI Learning Library — Planned.** Free learning resources, templates and exercises that educators and community contributors can adapt and share.

Planned means proposed: these modules are not currently implemented and should not be described as available features.

## Near term

- Add a real import flow in the UI for JSON and CSV files.
- Add keyboard shortcuts and stronger screen-reader announcements for save/export feedback.
- Add more worked examples with educator-reviewed explanations.
- Add a browser-only prompt diff view for highlighting changed instructions.

## Later

- Add optional, provider-agnostic response adapters without requiring a specific AI vendor.
- Add multilingual examples and plain-language translations.
- Add a lesson authoring format for community-created modules.
- Add end-to-end browser tests for the main learning journey.

## Principles

Privacy first, no required accounts, beginner clarity, accessible defaults, and useful code that can be forked independently of any commercial academy.

## Contribution paths

Developers can improve the application, tests, accessibility and import/export behavior. Educators can review examples, write exercises and propose learning sequences. Beginners can test the current labs, report confusing copy, improve documentation and contribute reproducible bug reports. See `CONTRIBUTING.md` for the workflow.
