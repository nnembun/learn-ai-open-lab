# Security Policy

## Scope

Learn AI Open Lab is a client-side educational application. Prompt text and notes are stored in browser local storage; the project does not require API keys or send prompt content to a project server.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's private security advisory feature once the repository is published, or contact the maintainer privately through the GitHub profile. Include the affected version, reproduction steps, impact, and a suggested fix if available. Do not include credentials or real personal data in a report.

## Supported versions

Security fixes target the latest default branch. This project is an educational toolkit and does not promise production support or a service-level agreement.
