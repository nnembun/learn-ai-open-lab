# Contributing to Learn AI Open Lab

Thank you for helping make practical AI education more accessible.

## Local setup

1. Fork and clone the repository.
2. Run `npm install`.
3. Run `npm run dev` for the app, `npm test` for tests, `npm run typecheck` for TypeScript checks, and `npm run build` for a production build.
4. Create a focused branch and make the smallest useful change.

## Pull requests

Describe the learner problem, what changed, how you tested it, and any accessibility or privacy considerations. Please do not include API keys, personal data, generated credentials, or fabricated usage claims. Keep the existing visual language unless the change is specifically about design.

## Code style

Prefer small, readable functions and browser-local behavior. Add or update tests for behavior changes. Keep copy beginner-friendly and explain AI concepts in plain language.

## Commit and review

Use a clear commit message. All tests and builds should pass before requesting review. By contributing, you agree that your contribution is provided under the MIT License.
